Opción 3: Selector / Dropdown en la Barra de Filtros
Mantiene el buscador y agrega un desplegable <select> para filtrar por estado.

+---------------------------------------------------------------------------------------+
| Libros                                                           [ + Nuevo libro ]    |
|                                                                                       |
|  [🔍 Buscar por título, autor...   ]  [ Estado: Solo Activos ▾ ]                      |

Comparativa rápidaOpciónProsContras1. Pestañas (Tabs)Explicita visualmente cuántos libros 
hay en cada estado; navegación de 
1 clic.Ocupa una línea vertical adicional.
2. Botón SecundarioMantiene la interfaz súper limpia; ideal si no se consultan los inactivos 
con frecuencia.Oculta los datos dados de baja tras un segundo nivel de navegación.
3. DropdownOcupa poco espacio y combina bien con futuros filtros (categorías, autores).
Requiere 2 clics para desplegar y seleccionar.
